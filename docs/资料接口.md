# 资料服务接口

数据库 db-b 将温度特性迁至句柄 37，句柄 33 改为另一特性。来源仍允许读取已排队的旧偏移片段，这些片段携带 db-a 解释依据，不能拼入新值。

HTTP 网关公开 GATT 服务和 ATT Read/Read Blob 的原始属性字节，并附设备连接、数据库哈希、可核对的记录版本。这里不声称 ATT 自带记录版本；version 是设备业务特性。没有版本的属性不能凭分片相邻就证明一致。Service Changed 范围是句柄闭区间。

本地服务的资料入口为 `/gatt/read/33?offset=0`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。

## 连续采集

读取身份由设备连接、属性语义（特征 UUID）和数据库哈希共同决定；句柄只是某一目录版本下的寻址方式，不作为身份。长属性按偏移分段读取，同一完整值只拼接连接、数据库哈希、特征与记录版本都一致且偏移连续的片段；版本不同、偏移缺口或内容冲突的片段被隔离并触发重读标记。无记录版本的属性不能凭分片相邻证明一致，只有单段完整的值才会被记录。

通知按收到时已核对的目录解析句柄，只有版本确实更新才覆盖当前值；通知到得晚不代表它比刚完成的长读更新。通知不携带连接身份，归入空连接身份，不与读取片段混排。Service Changed（句柄闭区间）或目录哈希变化后，采集器重新读取 `/gatt/services` 核对受影响服务，并把受影响特征标记为待重读；在旧目录下发出的请求即便此时才返回，也按响应自身的连接、特征和数据库哈希归档，不归入新目录。

采集状态（已核对目录、分段进度、完整值、待重读标记、已处理事件）持久化在数据目录 `collection/state.json`，断线或重启后可续传；重连本身不是继续相信旧句柄的依据，每轮采集都先重新核对目录再解析句柄。完整值同时写入原件目录并生成接收凭据。`POST /collection/run` 运行至稳定或达到周期上限，`GET /collection/status` 返回每个身份下的当前值、分段进度与待重读列表。`fixtures/drop.json` 记录长读中途断连再恢复的场景。
